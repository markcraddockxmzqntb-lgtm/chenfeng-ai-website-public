# Stage 76 — Production acceptance matrix

Stage 76 defines a release matrix for the bilingual Chenfeng AI website. It separates legacy route preservation, certificate and release safety, GPT chat, A2A read-only discovery, robots/sitemap/RSS/llms/service-catalog, bilingual CTA, desktop/mobile checks, Muse content operations, and post-release GEO sampling.

The current production gate remains closed because the apex certificate is expired and the apex still shares legacy backend responsibilities with duplicate or backup Nginx candidates. A location-level preservation map, restricted release account, isolated version directories, atomic switch, backup, rollback rehearsal, and formal URL readback are still required.

The matrix does not claim launch, AI indexing, citation, agent discovery, leads, or revenue. Sampling will keep platform, region, question language, and device dimensions separate; unsampled rates remain unknown. Muse continues to maintain only the website-owned bilingual `/insights/` and `/en/insights/` flow.
