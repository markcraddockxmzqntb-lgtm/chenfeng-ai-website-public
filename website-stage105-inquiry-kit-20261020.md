Prepared on 2026-10-20 for Chenfeng AI, operated by 马鞍山市尘风信息科技有限公司.

## What a visitor can use

The [kit guide](stage105-inquiry-kit-guide.md) provides a free [ZIP download](stage105-inquiry-workflow-kit.zip), a [Chinese brief](stage105-inquiry-brief-zh.md), an [English brief](stage105-inquiry-brief-en.md), a blank handoff CSV, three fictional examples in CSV and JSON, and a bilingual referral note for website, ERP and trade-service teams. The two briefs share twelve question IDs. They help a buyer describe one process, available inputs, expected output, approval points and missing dependencies before discussing a pilot.

The public repository README links to the kit and the existing website. The kit uses the website's registered operator and public WeChat/WhatsApp contacts. Completed copies remain with the user; the public repository is not a submission inbox. All example records are fictional, with no messages sent or CRM updates performed.

## Scope and checks

The download contains seven customer-facing files. It is a document kit, without executable code, model calls, registration, subscription or additional service costs. Checks cover the twelve aligned bilingual fields, CSV encoding and ten-column parsing, three cross-format examples, safe ZIP paths/CRC/member bytes, local Markdown links, public-file allowlisting and credential patterns. Thirteen existing website paths returned HTTP 200; the public service catalog reported content version 2026-10-19.2 and matching operator/contact details. These checks do not establish compatibility with every spreadsheet application; no Excel GUI test was performed.

The manifest lists the ten other public files with byte counts and SHA-256 hashes. It does not hash itself. It is a preparation-time snapshot: GitHub commit readback and Muse's content review are recorded separately after this upload, without rewriting the snapshot to imply earlier approval.
