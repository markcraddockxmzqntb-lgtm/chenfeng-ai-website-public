# Customer discovery plan: implementation decision

Updated 20 October 2026

The goal is to help mainland China and Hong Kong foreign-trade and cross-border commerce businesses discover Chenfeng AI's services and start a qualified conversation. The bilingual official website remains the content home; this plan does not add Zhihu or WeChat Official Account publishing.

## Chosen approach

- Reuse the existing Astro website, Python evidence and rules services, GEO workbench, and Muse review and publishing process.
- Use deterministic rules and human review for the first tool trial. The existing website GPT receptionist remains a separate feature.
- Start with evidence-backed procurement-question pages, one useful rule-based inquiry-workflow self-check, a public-safe resource, and a trackable referral path. Keep customer contact optional until the visitor has received the tool's result.
- Route voluntary inquiries through the existing sales handoff after its real interface and privacy requirements are verified.

## How results will be judged

Track search discovery, verified AI citations, website visits, tool use, voluntary inquiry, qualified conversation, human handoff, and commercial outcome as separate stages. A crawl, sitemap notification, API response, page view, contact-button click, or workflow run is not proof of a qualified lead or customer. Unknown evidence stays unknown.

## Delivery boundary

No new account, paid data source, third-party service, or recurring cost is required for the first rule-based trial. Production implementation still needs the existing release checks and a real end-to-end test of the visitor-to-inquiry handoff. No indexing growth, citation rate, lead volume, or revenue result is claimed by this plan.

Only this sanitized decision note and its manifest are public. Core source, credentials, customer records, and private platform evidence remain private.
